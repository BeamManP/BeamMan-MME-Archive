# ビームマンのエフェクト置き場

ビームマンPが作った MikuMikuEffect 用エフェクトの配布場所です。

**配布ページ: https://beammanp.github.io/BeamMan-MME-Archive/**

uploader.jp のサービス終了（2026年11月25日）に合わせて、atwiki（https://w.atwiki.jp/beamman/）と
uploader.jp の4つのアップローダ（BeamMan〜BeamMan4）から引っ越しました。

## ファイルの場所

- エフェクト本体は [Releases](https://github.com/BeamManP/BeamMan-MME-Archive/releases) にあります。旧アップローダごとに1つのリリースです
- Releases のファイル名は「アップローダ名_番号_英数字部分」です（GitHub が日本語のファイル名を扱えないため）。zip の中身はそのままです
- 元のファイル名・コメント・日付は `ledger/ledger_*.csv` に残しています。パスワード付きだったファイルは引っ越していません

## 利用規約

配布ページの「エフェクト利用規約」を見てください。
